# 강의공방 공개 소개

[소개 페이지와 사용법 영상](https://sisjinho.github.io/lecture-workshop-info/#video) · [글로 읽는 사용법](assets/how-to-use.md)

## 처음 사용하는 순서

1. GitHub 접근 승인을 받고 최신 ZIP을 다운로드합니다.
2. 압축을 풀고 `강의공방.html`을 엽니다.
3. 주제와 수업 조건을 적고 디자인 번호를 고릅니다.
4. GPT·Claude·Gemini와 제작 방식을 선택합니다.
5. 설명만으로 시작하거나, 관련 자료 한 개 이상 또는 기존 PPT를 선택합니다.
6. 프롬프트를 복사해 AI 대화에 붙이고 실제 자료 파일도 직접 첨부합니다.
7. 결과물의 사실·출처·화면을 확인하고 수정합니다.

영상은 실제 공방 화면을 담은 무음·한국어 자막 안내입니다. 가상 자료를 사용하며 외부 AI의 실제 생성 과정은 포함하지 않습니다.

이 저장소에는 공개 이용 안내와 사용법 영상만 포함합니다. 강의공방 본체·배포 ZIP·원본자료·개인정보·인증키는 포함하지 않습니다. 다운로드 인증은 별도 비공개 저장소의 GitHub 로그인과 접근 권한으로 처리합니다.
