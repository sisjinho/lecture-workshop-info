# 강의공방 사용법

[사용법 영상](https://sisjinho.github.io/lecture-workshop-info/#video) · [인증 다운로드](https://github.com/sisjinho/lecture-workshop-downloads/releases/latest)

영상: 약 1분 41초 · 무음 · 한국어 자막

## 시작하기

승인된 GitHub 계정으로 최신 릴리스의 ZIP을 받아 압축을 풉니다. 폴더 안의 강의공방.html을 열면 디자인 메인 페이지로 이동합니다. 견본은 오프라인에서도 열 수 있습니다.

## 번호와 조건 고르기

강의 주제·대상·시간·형식·언어를 정합니다. 필요한 경우3D 표현을 선택합니다. 원하는 번호를 열고 기본10장과 시각구성28장을 살펴봅니다. 표·그림·그래프·흐름·근거에 맞는 구성을 확인한 뒤 최종 프롬프트 만들기를 누릅니다.

## 세 가지 자료 조건

- 설명만 있으면 첨부 없이 주제와 요청으로 시작합니다. AI가 공식 자료를 리서치하고 강의안을 만듭니다.
- 관련 자료가 있으면 한 개 또는 여러 개를 선택합니다. 원자료 분석과 추가 리서치로 설명을 보강합니다.
- 기존 PPT가 있으면 PPT 재디자인을 선택합니다. 유지할 내용과 바꿀 부분을 추가 요청에 적습니다.

공방에서 선택한 파일은 이 페이지에서 외부로 전송되지 않습니다. 최종 프롬프트에는 파일 목록이 들어갑니다. 프롬프트를 AI 대화에 붙여 넣을 때 실제 파일도 해당 대화에 직접 첨부하세요. 로컬 에이전트에서는 공방 폴더를 작업공간으로 연결합니다.

## 복사한 다음

AI가 현재 환경과 필요한 스킬·MCP·도구를 확인하도록 프롬프트에 안내가 들어 있습니다. 이미 설치된 도구는 재사용합니다. 서비스별 설치·파일 처리·검색 지원은 실제 환경에서 확인합니다. 필요한 질문에는 대화로 답합니다.

완성한 강의안은 원자료·사실·수치·날짜·출처와 대조합니다. 표와 그림의 의미, 글자 잘림과 한글 표시를 확인합니다. HTML에서는 편집 모드(E)로 글씨와 위치를 고치고 저장한 파일을 다시 열어 확인합니다.

## 영상의 범위

영상은 공방의 실제 화면과 가상 교육 자료로 촬영했습니다. 로그인 자격증명과 실제 사건 자료는 사용하지 않았습니다. AI 대화에 프롬프트와 파일을 전달하는 단계는 자막으로 안내합니다. 마지막 편집 화면은 견본으로 기능을 시연합니다. 영상에는 외부 AI가 새 강의안을 생성하는 장면이 포함되지 않습니다.
