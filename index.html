처음 사용하는 순서

  1. GitHub 접근 승인을 받고 최신 ZIP을 다운로드합니다.
  2. 압축을 풀고 강의공방.html을 엽니다.
  3. 주제·대상·시간·형식을 적고 디자인 번호를 고릅니다.
  4. 표·그림·그래프·도식 견본을 확인합니다.

AI와 강의안 만들기

  1. GPT·Claude·Gemini와 제작 방식을 고릅니다.
  2. 자료를 선택하고 원하는 작업을 적습니다. 자료가 없어도 시작할 수 있습니다.
  3. 프롬프트를 복사해 AI 대화에 붙이고 실제 자료 파일도 첨부합니다.
  4. 결과물의 사실·출처·가독성을 검수하고 수정합니다.

파일 선택만으로 AI에 전송되지 않습니다. 공방에서는 프롬프트에 자료 목록을 반영합니다. 실제 파일은 AI 대화에 직접 첨부하세요. 로컬 AI에서는 공방 폴더를 작업공간으로 연결합니다. 이미 설치된 도구는 재사용하고 필요한 도구만 추가합니다.

영상은 공방 조작을 안내합니다. 외부 AI의 실제 강의안 생성은 포함하지 않으며, 마지막 편집 화면은 견본 시연입니다.
